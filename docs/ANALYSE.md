# Dein Tag – Benchmark, Ideen & Einschätzung

Stand: November 2026

## 1. Benchmark ähnlicher Apps

| App | Bereich | Was sie gut macht | Was fehlt |
|---|---|---|---|
| **Structured** | Tagesplaner (Kalender + To-dos + Habits als Timeline) | Sehr klare Timeline, „Replan“ für verpasste Aufgaben, vorbildliche Barrierefreiheit (VoiceOver, Legasthenie-Schrift, „nicht nur über Farbe“) | Kein Zyklus, keine Achtsamkeit, keine Auswertung über Lebensbereiche |
| **Tiimo** | Visueller Planer (ADHS-freundlich) | Farbcodierter Tag, Fokus-Timer, KI-Priorisierung, werbefrei | Kein Zyklus, wenig Gesundheitsdaten, Abo-lastig |
| **TickTick / Any.do** | To-dos + Kalender | Starke Aufgabenverwaltung, Pomodoro, Habits | Kaum Emotionen/Wohlbefinden, keine Belastungsanalyse |
| **Finch** | Self-Care + Gamification | Virtuelles Haustier, sehr warme, positive Motivation, großzügige Gratisversion | Kaum Planung (Kalender/To-dos), keine Gesundheitsdaten |
| **Habitica** | Gamifizierter Habit-Tracker | RPG-Logik, Gruppen-Quests, Belohnungen | Strafen bei Versäumnis wirken schnell demotivierend, wirkt verspielt, braucht Internet |
| **Fabulous** | Routinen-Coach | Verhaltenspsychologische Routinen, schöne UX | Teures Abo, wenig Freiheit bei eigenen Gewohnheiten |
| **Daylio** | Stimmungstagebuch | Sehr schneller Check-in, Muster zwischen Aktivität und Stimmung | Keine Planung, keine Termine |
| **Bearable** | Symptom-/Stimmungs-Tracker | Korrelationen zwischen Faktoren (Schlaf, Zyklus, Stimmung) | Eher technisch, wenig Motivation/Planung |
| **Clue / Flo** | Zyklustracker | Clue: wissenschaftlich, datensparsam. Flo: sehr viele Funktionen | Keine Verbindung zu Kalender/To-dos. Flo hatte Datenschutzprobleme |
| **Synca / Phase / Essence / Cycora** | Cycle-Syncing-Planer | Kalender mit Energie-Labels je Zyklusphase, Aufgaben nach Phase | Meist nur iOS, schmal im Funktionsumfang, teils teure Abos |
| **6-Minuten-Tagebuch, Headspace, YAZIO** | Einzelbereiche | Jeweils stark in ihrem Bereich | Insellösungen – Nutzer brauchen 5–8 Apps |

**Kernbeobachtung:** Jede App deckt 1–2 Bereiche ab. Niemand verbindet **Planung + Zyklus + Stimmung + Belastung** in *einer* datensouveränen App, die auch auf Android läuft.

## 2. Vorgeschlagene Zusatzfunktionen

| Funktion | Begründung |
|---|---|
| **Energie-/Kapazitäts-Budget pro Tag („Löffel“)** | Macht die Belastung sichtbar, bevor sie zu viel wird. Das ist der Kern der App-Idee |
| **Replan / „Auf morgen schieben“ mit einem Wisch** | Verpasste To-dos erzeugen sonst Schuldgefühle (Erfahrung aus Structured) |
| **Streak-Freeze / Pausentage** | Krankheit oder Urlaub sollen den Fortschritt nicht zerstören |
| **Wochenrückblick (Sonntag)** | Ein Ritual, das wiederkommen lässt, und eine natürliche Stelle für Erkenntnisse |
| **Schlaf- und Wasser-Tracker** | Die stärksten Einflussfaktoren auf Stimmung und Energie, einfach zu erfassen |
| **Arztbericht-Export (PDF)** | Zyklus, Beschwerden und Stimmung für die Frauenärztin. Clue verkauft das als Extra |
| **Home-Widget (Android)** | Ein Tipp für Check-in oder Habit, ohne die App zu öffnen |
| **Haustier/Avatar (optional)** | Finch zeigt, dass Fürsorge für eine Figur stärker motiviert als Punkte |
| **Familienmodus (später)** | Geteilte Einkaufsliste und Termine für die Zielgruppe Familien |
| **Notfall-/SOS-Übung** | 60-Sekunden-Atemübung, direkt vom Startbildschirm erreichbar |

## 3. Ehrliche Einschätzung: Wettbewerbsfähigkeit

**Chancen**
- Die Lücke „ganzheitliche Planung mit Rücksicht auf Kapazität und Zyklus“ ist real. Cycle-Syncing-Planer entstehen gerade erst und sind meist nur für iOS.
- **Datenhoheit** (lokal oder eigene Cloud, verschlüsselt) ist nach den Datenschutzskandalen bei Zyklus-Apps ein echtes Verkaufsargument, gerade in Deutschland.
- Android-first ist ein Vorteil: Viele Cycle-Syncing-Apps gibt es nur für iPhone.

**Risiken**
- **Feature-Überladung:** Viele Funktionen überfordern Anfänger. Deshalb müssen die Module an- und abschaltbar sein, und das Onboarding startet mit wenigen Modulen.
- **Konkurrenz pro Modul:** Gegen Spezialisten wie YAZIO oder Flo ist jedes einzelne Modul schwächer. Der Mehrwert muss aus der **Verknüpfung** kommen (Dashboard, Belastungswarnung).
- **Pflegeaufwand:** Lebensmitteldatenbank, Übungen und Store-Richtlinien für Gesundheitsdaten kosten laufend Zeit.
- **Monetarisierung:** Werbung passt schlecht zu „Achtsamkeit und Datenhoheit“. Ein Einmalkauf oder ein faires Abo für Cloud-Sync und Extras passt besser.

**Fazit:** Wettbewerbsfähig ist die App **nicht** als „alles in einer App“, sondern als **„Planer, der auf deine Kapazität achtet“**. Darauf sollten Marketing und Startbildschirm ausgerichtet sein.

## 4. Weitere Lebensbereiche für einen ganzheitlichen Ansatz

| Bereich | Was getrackt wird |
|---|---|
| Schlaf | Dauer, Qualität, Einschlafzeit |
| Trinken | Gläser Wasser pro Tag |
| Soziale Kontakte | Wen habe ich getroffen, tat es gut? („soziale Batterie“) |
| Finanzen | Ausgaben-Kategorien, Sparziele |
| Medikamente & Supplements | Einnahme-Erinnerung (allgemein, nicht nur Pille) |
| Natur & Draußen-Zeit | Minuten draußen, Tageslicht |
| Lernen & Lesen | Bücher, Kurse, Sprachen |
| Kreativität & Hobbys | Zeit für eigene Projekte |
| Haushalt | Wiederkehrende Aufgaben (Putzplan) |
| Beziehung & Partnerschaft | Gemeinsame Zeit, Date-Nights |
| Substanzen | Alkohol, Koffein, Nikotin |
| Dankbarkeit & Werte | Bereits im 6-Minuten-Tagebuch enthalten |
| Ziele | Langfristige Ziele mit Meilensteinen |

Die App enthält davon bereits **Schlaf, Wasser, soziale Batterie und Koffein/Alkohol** im Check-in. Weitere Bereiche lassen sich als Module ergänzen.
